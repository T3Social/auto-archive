# Auto Archive

Automatically archive inactive HumHub Spaces to keep your network tidy.

## Overview

- Scans all active Spaces daily via a cron job
- Archives a Space when **both** its last content **and** its last comment are older than a configurable number of days
- Optionally notifies space admins and the space owner by in-app notification and email when their space is archived
- Archiving can be disabled at any time by leaving the day threshold empty in the module settings

## Configuration

Go to **Administration → Modules → Auto Archive → Configuration**.
